# 🌍 Comparative Analysis of Air Quality in Europe (WHO Data)

## 📊 Project Overview
This project analyzes air quality across the European region using the WHO Ambient Air Quality Database (2024). The goal is to explore PM10 pollution patterns across countries and identify trends using data analysis and visualization techniques in R.

## 🎯 Objectives
- Clean and preprocess real-world WHO air quality data  
- Analyze PM10 annual mean concentrations  
- Compare air quality across European countries  
- Visualize pollution trends using ggplot2  

## 🗂 Dataset
Source: WHO Ambient Air Quality Database (2024)

The dataset contains country-level air pollution measurements including PM10 concentrations.

## 🛠 Tools & Technologies
- R  
- tidyverse  
- dplyr  
- tidyr  
- ggplot2  
- R Markdown  

## 🔍 Key Steps
- Data cleaning and handling missing values  
- Filtering European region data  
- Calculating annual mean PM10 levels  
- Creating comparative visualizations  
- Interpreting air quality trends  

## 📈 Key Insights
- Significant variation in PM10 levels across countries  
- Some countries consistently exceed recommended limits  
- Clear trends visible through time-series visualization
