# 🌍 Comparative Analysis of Air Quality in Europe (WHO Data)

## 📊 Project Overview
This project presents a comparative analysis of air quality across the European region using the WHO Ambient Air Quality Database (2024). The analysis focuses on PM10 pollution levels across countries and years using data cleaning, transformation, and visualization techniques in R.

## 🎯 Objectives
- Clean and preprocess real-world WHO air quality data  
- Analyze annual mean PM10 concentrations  
- Compare air quality across European countries  
- Visualize pollution trends using ggplot2  

## 🗂 Dataset
**Source:** WHO Ambient Air Quality Database (2024)

The dataset contains country-level air pollution measurements, including PM10 concentration values used to evaluate air quality patterns across Europe.

## 🛠 Tools & Technologies
- R  
- tidyverse  
- dplyr  
- tidyr  
- ggplot2  
- R Markdown  

## 🔍 Key Steps
- Data cleaning and handling missing values  
- Filtering European region data  
- Calculating annual mean PM10 levels  
- Creating comparative visualizations  
- Interpreting air quality trends  

## 📈 Key Insights
- PM10 levels vary significantly across European countries  
- Several countries consistently exceed recommended air quality limits  
- Time-series visualizations reveal noticeable pollution trends over time
